Асинхронный бот для работы с P2C мерчант API CryptoBot. Бот поддерживает несколько мерчантских ключей, автоматически принимает подходящие заявки и показывает состояние всех подключений в единой панели.

## Как ловить большие чеки?

В этом репозитории лежит только лёгкая наработка. Полноценный P2C-снипер на API/access_token ловит новые платежи, фильтрует их по сумме и делает тейк. Софт работает автоматически, ведёт статистику и имеет множество технических настроек для тонкой оптимизации.

Вся важная информация приходит в тг бота: сумма, QR-код, прямая ссылка и информация о заказе. Там же можно подтвердить/отменить оплату можно одной кнопкой, не переключаясь между приложениями. Недавно вышло крупное обновление, которое заметно увеличило скорость работы. Софт был переведён на CryptoBot API и была реализована адаптация мерчанта(-ов) под коррекцию статистики, сделанна защита от дублей, возможность заблокировать провайдерра мерчанта, адаптивные переподключения а сетевая часть получила дополнительные модификации для снижения задержек и повышения шансов в очереди.
